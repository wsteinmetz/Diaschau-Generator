Einfacher Dia Schau Generator für Linux Anwender auf ffmpeg Basis.
Einfach das Script in den zu bearbeitenden Ordner legen und per Terminal ausführen
1. chmod a+x Diashow_final.sh
2. das File im Terminal ausführen ./Diashow_Final.sh

Das Script kann *.png sowie *.jpg Files verarbeiten.

Einstellmöglichkeiten sind im Script erklärt
